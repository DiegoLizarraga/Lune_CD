**Card** — the notched surface panel; the default container for any grouped content (settings groups, info panels, Lune's stage).

```jsx
<Card eyebrow="// Red Neuronal" title="OpenRouter" tone="cyan" tick>
  <p>API conectada · 12 modelos disponibles</p>
</Card>
```

Tones: `default | raised | cyan | blue | yellow`. Toggle `notch` (signature cut corners, on by default), `grid` (technical grid texture), `scan` (scanline overlay), `tick` (cyan corner accent). Compose freely — a hero panel is often `tone="cyan" grid scan tick`.
